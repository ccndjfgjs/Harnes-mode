## Правила проекта
- UI-текст только через словари (`t('...')`), без хардкода.
- Русские фразы в озвучке оставлены намеренно (14.09.2026).
- `workspace/` в корне — рабочая папка пользователя, не мусор.
- Общий документ `dsh.voice.settings` читают **два** места (голосовой модуль и
  страница настроек). Запись — всегда «дополнить прочитанное», не «собрать
  заново из своего списка полей»: иначе одна сторона стирает поля другой.
- **Новый пункт настроек = ДВА пакета** (клиентская страница + пакет хоста), и
  **обоим** нужны пути в `tsconfig.base.json`. Имя, отличающееся от каталога
  (напр. `dsh-client-ui-settings-improve-text` в `ui-settings-improve-text`),
  генератор не берёт — **дописывать руками**.

## Настройки: где что лежит (18.09.2026)
`packages/client/ui-settings/src/client/index.ts:58`:
`const persistence = ctx.remote.$host.isLoopback ? 'host' : 'memory'`

- **Оконное приложение** (`isLoopback === true`) → запись уходит в
  `settings.yaml` в каталоге `~/.dsh`.
- **Страница в браузере** (`false`) → `memory`: запись **тихо не сохраняется**
  (`enqueue` → `Promise.resolve()`). «Настройки не сохраняются» в браузере —
  это норма, а не поломка.
- **Сеть/V2Ray — третий путь:** через мост `globalThis.harnessAPI` в главный
  процесс Electron (`ui-settings-network/src/client/v2ray-bridge.ts`).
- Секреты принимаются, но **обратно не отдаются** (`secrets:[{path,set:true}]`).
- Проверка сохранения — только в оконном приложении.

## ЗАПУСК и СБОРКА
**Запуск — один файл `Запуск_Harness.bat`:** снимает защитные обертки WorkBuddy →
убирает брошенный замок `~/.dsh/.credentials.yaml.lock` → проверяет
зависимости → запускает `electron/main.js`.

Обертки снимать обязательно: защита `CODEBUDDY_SAFE_DELETE_*` считает удаления
и после порога 50 отказывает → `atomic-write` не снимает свой замок → строка
`connection` не применяется → **дерево плагинов падает целиком**. Брошенный
замок можно удалять вручную — код его намеренно не трогает.

**Тот же замок ломает запись настроек:** `atomic-write: timed out waiting for
the writer lock at ...settings.yaml.lock`. На чистом сервере та же проба
проходит за 154 мс. Ремедия: удалить `~/.dsh/settings.yaml.lock`.

**`pnpm` и `pnpm run build:web` не работают** — `pnpm` сам зовёт `install` и
падает на той же защите. Собирать напрямую (команды — в `ПОДРОБНОСТИ.md`).

**Правило сборки:** пересборка `packages/client/*/lib/client.js` **не
обновляет** страницу. Нужны обе половины: библиотека **и** `apps/web/dist`.
Иначе сервер отдаёт ссылку на файл, которого нет → пустое окно без поля ввода.

**Как проверять «функция в интерфейсе»** — не `grep` по файлу плагина, а
запросами к серверу. Команды и тонкости (`curl --noproxy '*'`, `&rev=`) — в
`ПОДРОБНОСТИ.md`.

## ОПАСНО: не использовать `git stash` и `git checkout --`

Репозиторий стоит на промежуточном коммите, и бóльшая часть рабочего дерева —
**неотслеживаемые добавления** (файлы в состоянии `A`/`AD`). `git stash push`
по одному файлу **выносит из рабочей папки и остальные** такие файлы, а
`git checkout -- <каталог>` **откатывает незакоммиченные правки насмерть**.
18.09.2026 так были стёрты `electron/port-selector.html`, `v2ray.js`,
`oauth-flow.js` и все тесты; пришлось восстанавливать вручную.

Для сравнения «как было до правки»: копия рядом (`cp f f.bak`) или
`git show HEAD:путь`. Никаких `stash`/`checkout`, кроме случая, когда
пользователь прямо об этом попросил.

## Диагностика, уже подтверждённая
- **«Backend failed to start in time» (окно Electron).** `electron/main.js` ждёт
  строку `dsh web: http://127.0.0.1:<порт>/?token=...` и по таймауту выдаёт эту
  фразу. Частая причина — **новый пакет хоста без `node_modules`** роняет всё
  дерево. Как воспроизвести вручную и как лечить линками — в `ПОДРОБНОСТИ.md`.
- **Генерация словарей/путей:** `tsx scripts/gen-tsconfig-paths.ts`,
  проверка — `--check` → «aliases are current».
- «Искра» (`restructureDraft`) показывает реальную причину ошибки (в т.ч. 429).
- OpenRouter: все `:free` модели расходуют общий бесплатный лимит аккаунта.
- Google API: возможен региональный отказ `User location is not supported`.
- **`DOMException` не является `Error`** (jsdom; в приложении вёл себя так же).
  Проверка `instanceof Error` **молча теряет и имя, и текст** отказа.
- `symlinkSync(file)` на Windows → `EPERM` без прав администратора/режима
  разработчика; junction и жёсткие ссылки работают. Это **не** дефект продукта.

## V2Ray
Раздел «Сеть» + блок в окне запуска работают; прокси-цепочка исправлена
(`socks` + `http`); установка движка с прогрессом и зеркалами; таймаут только
по неактивности. **Детали установки, зеркал и разбора 8% — в `ПОДРОБНОСТИ.md`.**

Главное одной строкой: **«встало на 8%» — это проверка контрольной суммы, а не
загрузка**; формат суммы v2fly — `SHA2-256= <хеш>`, не `SHA256(файл)= <хеш>`.

**Установка и удаление — только в окне запуска** (`electron/port-selector.html`).
В настройках приложения (`ui-settings-network`) **нет ни того, ни другого** —
там лишь подсказка. Удаление (`scripts/remove-v2ray-core.mjs`): **сначала останов
туннеля**, потом `.download`, потом точные имена файлов; `README.txt` не
трогается. При неудаче окно **не говорит «удалено»**, а оставляет повтор.

**ПАРА КНОПОК: управляет `disabled`, НЕ `hidden` (18.09.2026).**
- **Скрытая кнопка не принимает нажатий.** `hidden` убирает её из попадания →
  нажатие уходит в элемент под ней → «кнопка ничего не делает».
- **`hidden` — лишь догадка браузера,** её отменяет любое правило `display` от
  класса (в этом файле перебивал `.hidden { display: none !important }`).
  Добавлено `.btn[hidden] { display: none }`. **Обе кнопки всегда на месте.**
- **Ни одна ветка действия не выходит раньше отрисовки.** Досрочный `return`
  при успехе оставил кнопку в состоянии «идёт работа» навсегда — это и была
  жалоба «бесконечный цикл не удаляет».
- **После действия состояние берётся из ОТВЕТА, а не из памяти окна.**
- Единая точка отрисовки — `updateCoreInstallButton(binaryAvailable, busy)`.

**Ошибка видна там, где на неё смотрят.** Раздел V2Ray может быть прокручен
вверх, поэтому причина отказа дублируется в блоке под кнопкой «Запустить
Harness» (`reportTunnelFailure` / `clearTunnelFailure`), а `refreshProxyPlan`
предупреждает заранее, если туннель включён, а движка нет.

**СЕТЬ ЭТОЙ МАШИНЫ: зеркала не отдают архив (18.09.2026, проверено живьём).**
Все шесть зеркал из списка источников при скачивании архива отвечают «206» с
верным размером, но **тела не приходит — ноль байт** (и через `curl`, и через
`fetch`). Прямой `github.com` качает нормально (~1.5 МБ/с). Список источников
**менять не нужно** — github идёт в нём последним, и установщик доходит до него
сам. Но при жалобе «медленно / встало» причина, скорее всего, здесь.

**Докачка проверена живьём и работает.** Вывод установщика на недокачанном
файле: `найден недокачанный файл (3.0 МБ), продолжаю` → `докачиваю github.com
с 2.0 МБ` → 100% → папка `.download` вычищена. Приём для повторной проверки:
скачать кусок через `curl --range 0-3145727`, положить рядом `*.part.json` с
**заниженным** `loadedBytes` и тем же адресом, запустить установщик с
`DSH_V2RAY_SOURCES=<прямой github>`. Подробности — в `2026-09-18.md`.

**Правя `port-selector.html`, помнить:** это HTML с инлайновым JS. Новый вызов
оболочки обязан быть: 1) в `preload.js`, 2) в `handleChannels` в
`electron/tests/shell-security.test.js`, 3) заглушкой в `mount()` в
`port-selector-v2ray.test.js`. Иначе тесты падают или (хуже) канал остаётся
без проверки защиты.
**Тестам про видимость не верить:** в JSDOM нажатие **доставляется и по
`hidden`-элементам**, поэтому тест «нажмёт» кнопку, которой человек не видит.
Для настоящей проверки — `getComputedStyle(el).display`. Приборы и разбор:
`2026-09-18.md`.

## Живая проверка оконного приложения — ограничение сессии

`electron.exe` не остаётся). Поэтому кнопки окна проверяются **повтором того же
пути**: тот же файл `port-selector.html` через JSDOM + та же заглушка
`harnessAPI`. Живую проверку в окне пользователь делает сам.
Установку V2Ray **через сеть** проверить можно, когда из оболочки есть сеть
(`curl` → не `000`): 18.09.2026 так проверены и докачка, и удаление — см. выше.
